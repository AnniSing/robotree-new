SetDash

SetDash([float black, float white])

Description

Sets the stroke line dashing pattern using native PDF graphic state operators ([black white] 0 d). This enables drawing decorative dashed lines, signature baselines, and security borders on certificates.

Calling SetDash() without arguments restores the default solid continuous line pattern ([] 0 d).

Parameters

black
Length of the colored dash segment in points/user units. Optional.
white
Length of the blank whitespace gap between dashes in points/user units. Optional.

Example

// Draw a dotted name separator line:
$pdf->SetDash(1.5, 1.5);
$pdf->Line(50, 70, 247, 70);

// Reset back to solid line:
$pdf->SetDash();
$pdf->Rect(10, 10, 277, 190);
