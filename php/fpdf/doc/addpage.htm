AddPage

AddPage([string orientation [, mixed size [, int rotation]]])

Description

Adds a new page to the PDF document. If a page already exists, the Footer() method is first called to output the footer, followed by adding the new page and invoking Header().

The origin of coordinates (0, 0) is situated at the top-left corner, and positions increase downwards and to the right.

Parameters

orientation
Page orientation:
  • P or Portrait - Tall / vertical format (210 × 297 mm for A4)
  • L or Landscape - Wide / horizontal format (297 × 210 mm for A4; standard for diplomas and certificates)
Default is the orientation passed to constructor.
size
Page size format: A3, A4, A5, Letter, Legal, or an array with [width, height] in millimeters.
rotation
Angle by which to rotate the page. Must be a multiple of 90 degrees (0, 90, 180, 270). Default is 0.

Example

$pdf = new FPDF('L', 'mm', 'A4');
$pdf->AddPage('L', 'A4'); // Certificate Landscape
$pdf->SetFont('Times', 'B', 30);
$pdf->Cell(0, 20, 'Arjun Sharma', 0, 1, 'C');
