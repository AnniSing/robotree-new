RoundedRect

RoundedRect(float x, float y, float w, float h, float r [, string corners [, string style]])

Description

Outputs a rectangle with smooth rounded corners calculated via high-precision cubic Bézier curves (using constant κ = 4/3 × (√2 − 1) ≈ 0.55228).

Supports selective rounding of individual corners:
  • 1: Top-left
  • 2: Top-right
  • 3: Bottom-right
  • 4: Bottom-left
  • Default: 1234 (all four corners rounded)

Parameters

x, y
Coordinates of the upper-left corner.
w, h
Width and height of the rectangle.
r
Radius of the rounded corners in user units (e.g. millimeters).
corners
String indicating which corners to round: any combination of 1, 2, 3, 4.
style
Rendering style: D (draw outline), F (fill background), DF or FD (fill and stroke outline). Default is D.

Example

// Draw a filled badge with rounded corners:
$pdf->SetFillColor(0, 128, 60); // Robotree Emerald
$pdf->SetDrawColor(212, 175, 55); // Gold Accent
$pdf->RoundedRect(80, 40, 137, 12, 3, '1234', 'DF');
