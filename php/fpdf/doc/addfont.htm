AddFont

AddFont(string family [, string style [, string file]])

Description

Imports a TrueType, OpenType, or Type1 font into the PDF document. Before invoking this method, a font definition file (.php) and compressed font file (.z) must be generated using makefont/makefont.php.

The definition file must reside in the directory pointed to by FPDF_FONTPATH (or the current directory), otherwise a fatal "Could not include font definition file" error occurs.

In the Robotree Certificate Generator, the wrapper method SafeAddFont() and SafeSetFont() is provided, which verifies file presence on disk and automatically falls back to standard core fonts (e.g. Times, Helvetica) without halting execution.

Parameters

family
Font family name chosen by the developer (e.g. Cinzel, Montserrat, GreatVibes). If matching a standard font family, it overrides it.
style
Font style. Possible values:
  • empty string: Regular
  • B: Bold
  • I: Italic
  • BI or IB: Bold Italic
Default is regular.
file
Font definition file name. Default is <family><style>.php in lowercase without spaces.

Example

// 1. Compile font definition (one-time offline):
// require('makefont/makefont.php');
// MakeFont('fonts/Cinzel-Bold.ttf', 'cp1252', true);

// 2. Load in certificate:
$pdf = new FPDF();
$pdf->AddFont('Cinzel', 'B', 'cinzelb.php');
$pdf->SetFont('Cinzel', 'B', 28);
$pdf->Cell(0, 10, 'CERTIFICATE OF ACCREDITATION', 0, 1, 'C');
