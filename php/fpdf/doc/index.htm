FPDF Reference Manual (v1.86 Enterprise)

Official reference documentation for all FPDF core methods, vector extensions, and certificate generation hooks.

Document Lifecycle & Structure

  • FPDF() - Class constructor
  • AddPage() - Add a new page (supports Portrait 'P' and Landscape 'L')
  • AcceptPageBreak() - Accept or reject automatic page break
  • SetAutoPageBreak() - Set automatic page break mode and triggering margin
  • Header() - Page header handler
  • Footer() - Page footer handler
  • PageNo() - Get current page number
  • Close() - Terminate document
  • Output() - Send document to browser, file, download, or string

Typography & Fonts

  • AddFont() - Load and register a custom TrueType/OpenType font
  • SetFont() - Set active font family, style, and size
  • SetFontSize() - Set font size in points
  • GetStringWidth() - Compute the length of a string in current font

Text Output

  • Text() - Print string at absolute coordinates (x, y)
  • Cell() - Print a standard rectangular cell with optional border and background
  • MultiCell() - Print text with automatic line breaks
  • Write() - Print running text with automatic wrapping

Graphics, Colors & Vector Geometry

  • Line() - Draw vector line between (x1, y1) and (x2, y2)
  • Rect() - Draw rectangle with outline, fill, or both
  • RoundedRect() - Draw smooth rounded corner rectangles with Bézier curves
  • SetDash() - Set vector dashed/dotted stroke pattern
  • Image() - Output image (JPEG, PNG, GIF) onto page
  • SetDrawColor() - Set line and border stroke color (RGB or Grayscale)
  • SetFillColor() - Set background fill color
  • SetTextColor() - Set text font color
  • SetLineWidth() - Set vector line thickness

Positioning & Margins

  • GetX() / GetY() - Get current position
  • SetX() / SetY() / SetXY() - Set current position
  • SetMargins() - Set left, top, and right margins
  • SetLeftMargin() / SetTopMargin() / SetRightMargin()
