AcceptPageBreak

boolean AcceptPageBreak()

Description

Whenever a page break condition is met (such as text or cell output exceeding the page boundary), this method is called automatically by FPDF. The page break will only occur if the function returns true.

In high-security certificate generation, overriding AcceptPageBreak() is critical:
  • Single-Page Certificate Mode: Returning false strictly guarantees that content will never accidentally leak into an unintended second page.
  • Multi-Page Transcript Mode: Returning true allows seamless generation of Page 2 (Competency Transcript & Government of India Accreditation Record).
This function is invoked internally by FPDF; it is rarely called directly.

Example

class RobotreeCertificate extends FPDF
{
    protected $allowMultiPage = false;

    function setAllowMultiPage($allow)
    {
        $this->allowMultiPage = (bool)$allow;
    }

    function AcceptPageBreak()
    {
        // Suppress automatic page breaks for single-page diploma
        if (!$this->allowMultiPage) {
            return false;
        }
        return true;
    }
}
